# Java OOP and Data Structures

This repository contains academic projects developed in Java, focused on object-oriented programming (OOP) and fundamental data structures. These projects reflect the application of programming concepts in problem-solving and teaching environments.

---

## 📌 Projects Included

### ✈️ Airline Management System
- Developed using Object-Oriented Programming principles
- Simulates an airline system for passenger management and reservations
- Demonstrates concepts such as classes, inheritance, and modular design

---

### 📚 Data Structures Teaching Material
- Collection of code examples used for teaching data structures
- Includes implementations of basic structures and algorithms
- Designed to support learning and explanation of core concepts
